Local Notes (Funicular local database)

A server-less demo of the local database layer: storage :local, .local queries, watch, snapshot persistence, the single-writer election, and Funicular::DB.wipe.

  • Add some notes, then reload the page. The writer tab snapshots the database into IndexedDB about half a second after the last write, and the next visit restores it.
  • Open this page in a second tab. Only one tab per browser profile wins the writer election; the other becomes a persistent reader whose writes raise. Close the writer tab and reload the reader to take over.
  • Press "Wipe everything". Both databases of this namespace are dropped and rebuilt empty, the stored snapshots are deleted, and the watcher re-renders onto empty tables.
  • The list re-renders through watch(:notes) { Note.local.order(created_at: :desc) } after every change event; no manual state bookkeeping.
